# AI Sharing Workshop Skill

把零散的大纲、个人经历、真实素材和公开资料，策划成可信、清楚、可讲的 AI 分享会，并交付可投影的 HTML 演讲稿、逐页讲述提示和来源说明。

这个 Skill 源自一次完整的 35 页 AI 分享会共创实践，沉淀了四类方法：

- 从听众目标反推章节、页面与讲述节奏；
- 区分亲历、官方事实、二手资料、生成示意和个人判断；
- 用大字、强层级、真实截图和渐进展开制作现场 HTML 演示；
- 从演讲者与听众两个视角验收内容，并检查离线、投影与手机布局。

## 使用

将 `ai-sharing-workshop` 文件夹复制到 Codex Skills 目录，或从本仓库安装该子目录。然后在任务中使用：

```
Use $ai-sharing-workshop to turn my outline and materials into an evidence-backed HTML talk with speaker notes.
```
